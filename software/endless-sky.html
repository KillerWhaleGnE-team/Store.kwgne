About this software

A 2D space game where you start with one ship and a little money, then trade, explore, take on missions, and build up a fleet. There's no set path, so you decide how to play.

Credit and license

Endless Sky was created by Michael Zahniser and is developed by a community of contributors. The code is under the GPL, and most art and sound assets use Creative Commons licenses. Check the project's license notes before reusing any of it. Platform availability changes over time, so check the official site for the builds that are current.
