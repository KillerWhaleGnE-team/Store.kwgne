About this software

KW Drivr Hlth Chkr (Driver Health Checker) is a Windows driver scanner. It looks over every device on your PC and tells you which drivers need attention, which are worth updating, and which are fine — with a plain-English reason for every call. Everything runs on your own machine, and it's free.

How to run it (the .exe)

  1. Download DriverHealthChecker.exe using the button above.
  2. Double-click it. That's the whole install — there isn't one. Save it wherever you like.
  3. If Windows says "Windows protected your PC," click More info, then Run anyway. This is normal for the first run (see the note below).
  4. Wait for the scan. It starts automatically and takes about 30–90 seconds the first time.
  5. Read your results. Worst drivers are listed first.
Why does Windows warn me? The .exe isn't code-signed — that takes a paid certificate we don't have yet — so SmartScreen shows a caution screen for any unsigned app it hasn't seen much. Some antivirus tools are also jumpy about any app built with PyInstaller (the tool used to package it into a single .exe), and may flag it as a false positive. Nothing in it is hidden: the entire source is in the zip above, and you can build the .exe yourself from it.

Using the app

  • Sort: click a column heading to sort, click again to reverse. Worst-first by default.
  • Filter & search: use the filter buttons and search box to narrow the list.
  • Details: click a row to see its details, including a plain-English "Why this status." Double-click (or right-click → View Full Details) for the full popup.
  • Right-click extras: search the driver online (opens your browser), or jump to Device Manager / Windows Update.
  • Rescan: refreshes the results without restarting the app.
  • Run as Admin: not needed — the scan only reads information any user can read. The button is in the top bar if you ever want it.

What the statuses mean

Update NecessaryDevice Manager reports an error code, the driver is unsigned, or a device has no driver installed at all.
Update SuggestedWindows Update has a pending driver for that device, Windows is using the generic "Basic Display Adapter," or the driver is old — 5+ years for GPU, network, storage, audio, Bluetooth, and firmware; 7+ years for everything else.
Update AvailableThe driver is 3+ years old.
Up to DateNothing found.

Drivers that ship with Windows itself (Microsoft's own, "(Standard …)" devices, and anything with a built-in INF name) aren't flagged for age — they carry old dates like 2006, but Windows Update looks after them.

Good to know: this is a smart heuristic, not a vendor lookup, so it can't promise a newer driver exists. For the most reliable results, use it alongside Windows Update and your PC or motherboard maker's support page. BIOS/UEFI is shown with its date, but Windows can't tell whether a newer one is out.

Privacy

No account, no tracking, and nothing is sent to us. The scan reads your driver info locally. The only outside contact is Windows' own Windows Update search (the same one Windows uses), and the optional "search online" right-click, which just opens a web search in your browser.

Run it from source instead

  1. Install Python 3.8+. Tick Add Python to PATH and keep tcl/tk and IDLE ticked.
  2. Download and unzip the source above.
  3. Double-click Run_DriverHealthChecker.bat (or run py main.py).

Want your own .exe? Double-click build_exe.bat in the same folder — it installs PyInstaller and produces DriverHealthChecker.exe in a minute or so. No extra packages are needed to run the app itself; it only uses Python's standard library.

If something goes wrong

The app saves error details to %LOCALAPPDATA%\KWDriverHealthChecker\error.log. Paste that into your message on the Support page and we can figure out what happened.

What's new in v2

Fixed

  • Works properly as a packaged .exe (the old admin relaunch would have broken).
  • No more crash when searching if a driver had no provider listed.
  • Clicking a row now shows the right driver when several devices share a name (like the many "USB Root Hub" entries).
  • Windows' built-in drivers (dated 2006 and similar) are no longer all marked "Suggested."
  • Windows Update matching now uses hardware IDs and exact models, instead of loose word overlap that could flag every Intel device because of one pending update.
  • Device error codes are actually checked now, and devices with no driver installed show up too.
  • Non-English device names display correctly.
  • Windows Update failures (like being offline) are reported in the status bar instead of failing silently.
  • Version, date, and status sorting work properly (no more "10.0" sorting before "9.0").
  • "Search online" encodes the query correctly and no longer always says "Windows 11."
  • The window now uses the app icon, and the scan no longer touches the UI unsafely.

Improved

  • The scan runs its four queries in parallel, so it's noticeably faster.
  • Crisp on high-DPI screens, with a progress bar while scanning and your OS/model shown in the header.
  • A "Why this status" explanation for every item.
